# Azure Data Engineering Project

## Overview
This project demonstrates my hands-on learning of Azure Data Engineering using Microsoft Azure services.

## Technologies Used
- Azure Data Factory (ADF)
- Azure SQL Database
- Azure Storage Account
- Azure Blob Storage
- GitHub

## Project Implementation
- Created an Azure SQL Database.
- Created an Azure Storage Account and Blob container.
- Developed a Copy Data pipeline using Azure Data Factory.
- Configured a Schedule Trigger to automate pipeline execution.
- Integrated GitHub for source control and version management.

## Learning Objectives
- Understand Azure Data Factory components.
- Build and execute data integration pipelines.
- Configure scheduled triggers.
- Understand Azure storage and database integration.
- Practice source control using GitHub.
